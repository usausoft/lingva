# Roadmap

This page describes planned public integration and distribution work. See [Progress](/progress) for implemented SDK and customer CLI capabilities.

<span id="current-phase-strengthen-the-platform-core" />
<span id="platform-expansion" />

## Runtime integrations {#runtime-integrations}

- Publish and stabilize Swift, Kotlin, and Flutter clients in ecosystem registries. Current clients are source previews.
- Add compatibility layers for `i18next` and `react-intl`.
- Expand request-scoped server integration and framework preload recipes.
- Add further adapters as shared runtime and bundle contracts stabilize.

<span id="next-phase-productize-delivery-and-collaboration" />

## Developer workflows {#developer-workflows}

- Expand CI recipes for monorepos and multi-application workspaces.
- Improve context and discussion around translation keys.
- Extend import/export beyond normalized JSON resources.
- Improve guidance for measuring missing keys, fallback use, and bundle freshness.

<span id="commercial-and-operational-maturity" />

## Delivery and distribution {#delivery-and-distribution}

- Strengthen hosted artifact controls and explore bundle signing.
- Provide an operator-supported self-hosted bootstrap and documentation.
- Verify publication provenance for supported distribution channels. A released package does not by itself guarantee provenance.

<span id="longer-term-product-bets" />

## Translation assistance {#translation-assistance}

- Expand in-context editing across review workflows.
- Add translation suggestions with human review.
- Develop more content-quality checks.

These items are direction, not guarantees of availability or release dates. Existing customer commands are documented in the [CLI reference](/installation/cli).
