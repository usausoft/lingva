# Список готовых возможностей

Этот список отслеживает возможности публичных SDK и клиентского CLI. Поддержка в исходном коде и публикация — разные вещи: способы установки и распространения описаны в разделах [CLI](/installation/cli) и [Нативные пакеты](/installation/native-bundles).

## Среда выполнения и SDK {#runtime-and-sdks}

- [x] Поиск по локали, резервные значения, подстановка переменных, вложенные ключи и типизированные варианты
- [x] Локальная загрузка пакетов и облачная загрузка с аутентификацией
- [x] TTL кэша в памяти, фоновая повторная проверка и явное обновление кэша
- [x] Адаптеры React, Next.js, Angular, Vue, Svelte, Docusaurus и Electron
- [x] Примеры интеграций Node, Angular SSR, Nuxt и SvelteKit с отдельной средой выполнения на запрос
- [x] Среда выполнения переводов Python с локальными и облачными клиентами
- [x] Версионированные тестовые пакеты и клиенты Swift, Kotlin и Flutter в исходном коде
- [x] Общие контракты ключей переводов и переносимых пакетов

## Клиентский CLI {#customer-cli}

- [x] Единый движок на Rust для всех клиентских команд с установочными адаптерами npm и Python
- [x] Локальная начальная настройка и генерация интеграций с фреймворками
- [x] Проверка, извлечение ключей, метаданные, манифесты, пакеты, типы и вспомогательные модули
- [x] Импорт, экспорт, синхронизация переводов и проверка расхождений в CI
- [x] Облачные pull/push с защитой от конфликтов, проверкой ревизий и идемпотентностью
- [x] Получение списка облачных черновиков, проверка, одобрение, публикация и инвалидация
- [x] Вход через браузер по OAuth, сохранённые учётные данные и обновление токенов
- [x] Вход с устройства, если выбранный провайдер OAuth его поддерживает
- [x] Аутентификация по API-ключам с областью действия проекта
- [x] Локальный предварительный просмотр в studio и безопасное применение экспортированных переводов
- [x] Генерация GitHub Actions для локального режима

## Публичное распространение {#public-distribution}

- [x] Сохранение лицензий Lingva для публичного кода и пакетов
- [x] Защищённые сборки JavaScript без карт исходного кода среды выполнения
- [x] Проверка упакованных артефактов и установочных адаптеров клиентского CLI
- [x] Процессы выпуска публичных SDK и отдельные установочные адаптеры CLI
- [x] Запускаемые локальные примеры без облачных учётных данных
- [ ] Публикация и стабилизация нативных SDK в реестрах их экосистем
