# Обзор документации

Выберите руководство по задаче, которую нужно решить. Рекомендуем начать с Remote: создайте проект Lingva, подключите приложение и публикуйте переводы. Local остаётся запасным вариантом для автономной доставки.

<span id="what-belongs-in-docs" />

## Настройте проект {#set-up-a-project}

- [Обзор установки](/installation/overview): установка CLI и подключение проекта Remote.
- [Варианты интеграции](/installation/integration-paths): выбор SDK и режима доставки.
- [Настройка](/installation/configuration): переносимая конфигурация и сгенерированные артефакты.
- [Миграция статического JSON](/migration/from-static-json): импорт существующих переводов.

## Подключите приложение {#integrate-an-application}

- [JavaScript](/installation/js), [React](/installation/react) и [Next.js](/installation/nextjs).
- [Angular](/installation/angular), [Vue](/installation/vue) и [Svelte](/installation/svelte).
- [Python](/installation/python).
- [Node, Electron и Docusaurus](/installation/server-and-site-adapters).
- [Нативные пакеты](/installation/native-bundles): предварительные реализации Swift, Kotlin и Flutter.
- [Микрофронтенды](/installation/microfrontends): разделение владения средой выполнения между приложениями.

## Доставляйте и автоматизируйте переводы {#deliver-and-automate-translations}

- [Справочник CLI](/installation/cli): команды, побочные эффекты и поведение в CI.
- [Рабочее пространство клиента](/workspace): проекты, переводы, проверка и доставка.
