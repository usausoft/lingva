# Знакомство с Lingva

Lingva предоставляет среды выполнения для переводов, клиентский CLI и переносимые ресурсы переводов. Начните локально без учётной записи, а затем подключите облачную доставку, когда она понадобится приложению.

## Что доступно сейчас {#what-you-can-use-today}

- Поиск переводов в JavaScript, резервная локаль, подстановка переменных, типизированные ключи и варианты.
- Интеграции с React, Next.js, Angular, Vue и Svelte.
- Адаптеры среды выполнения для Node, Electron и Docusaurus.
- Python-пакет `lingva-sdk` для локальной загрузки переводов и облачной загрузки с аутентификацией.
- Единый движок CLI на Rust с установочными адаптерами для npm и Python.
- Проверка, извлечение ключей, импорт и экспорт, генерация типов, манифестов и пакетов переводов.
- Облачные pull/push, проверка черновиков, публикация и обновление доставки через клиентские команды.

Клиенты Swift, Kotlin и Flutter доступны как предварительные реализации в исходном коде. Публикация в реестрах этих экосистем ещё запланирована. См. [Нативные пакеты](/installation/native-bundles).

Адаптеры CLI для npm и Python опубликованы в версии `0.1.5`. Руководства описывают текущий код репозитория; проверяйте установленный CLI командой `lingva --version`.

## Начните с локальной доставки {#start-with-local-delivery}

1. [Установите CLI](/installation/overview).
2. Выполните `lingva init --mode local --no-auth --sdk vanilla` или выберите SDK своего фреймворка.
3. Отредактируйте `.lingva/translations/{locale}.json` и выполните `lingva sync`.
4. Используйте сгенерированную интеграцию в приложении.
5. Запускайте `lingva check` в CI, чтобы выявлять ошибки проверки и расхождения сгенерированных файлов.

Локальная доставка использует ресурсы репозитория и не требует облачных учётных данных. Различия локальных и удалённых источников описаны в разделе [Настройка](/installation/configuration).

## Переносимые ресурсы {#portable-resources}

JSON-файлы переводов и сгенерированные пакеты остаются частью процесса доставки приложения. Можно импортировать существующие ресурсы, экспортировать переводы и выбирать локальную или облачную загрузку.

Публичные SDK и клиентские инструменты доступны под соответствующими лицензиями Lingva. Облачные сервисы — отдельный продукт. Поддерживаемый оператором процесс самостоятельного развёртывания ещё запланирован.
