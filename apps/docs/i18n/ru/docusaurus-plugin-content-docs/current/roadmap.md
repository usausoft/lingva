# План развития

Здесь описана запланированная работа над публичными интеграциями и распространением. Реализованные возможности SDK и клиентского CLI перечислены в [списке готовых возможностей](/progress).

<span id="current-phase-strengthen-the-platform-core" />
<span id="platform-expansion" />

## Интеграции среды выполнения {#runtime-integrations}

- Опубликовать и стабилизировать клиенты Swift, Kotlin и Flutter в реестрах экосистем. Сейчас это предварительные реализации в исходном коде.
- Добавить слои совместимости с `i18next` и `react-intl`.
- Расширить серверные интеграции с отдельной средой выполнения на запрос и примеры предварительной загрузки для фреймворков.
- Добавлять адаптеры по мере стабилизации общих контрактов среды выполнения и пакетов переводов.

<span id="next-phase-productize-delivery-and-collaboration" />

## Процессы разработки {#developer-workflows}

- Расширить примеры CI для монорепозиториев и рабочих пространств с несколькими приложениями.
- Улучшить контекст и обсуждение ключей переводов.
- Расширить импорт и экспорт за пределы нормализованных JSON-ресурсов.
- Улучшить рекомендации по измерению отсутствующих ключей, использования резервных значений и свежести пакетов переводов.

<span id="commercial-and-operational-maturity" />

## Доставка и распространение {#delivery-and-distribution}

- Усилить контроль облачных артефактов и изучить подпись пакетов переводов.
- Предоставить поддерживаемый оператором процесс самостоятельного развёртывания и документацию.
- Проверять подтверждение происхождения для поддерживаемых каналов распространения. Сам факт публикации пакета не гарантирует такое подтверждение.

<span id="longer-term-product-bets" />

## Помощь с переводами {#translation-assistance}

- Расширить редактирование в контексте на процессы проверки.
- Добавить предложения переводов с проверкой человеком.
- Развивать проверки качества содержимого.

Эти пункты задают направление, но не гарантируют доступность или даты выпуска. Существующие клиентские команды описаны в [справочнике CLI](/installation/cli).
