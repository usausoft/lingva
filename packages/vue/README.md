# `@lingva/vue`

Vue plugin and Composition API bindings for the Lingva localization runtime.

```bash
pnpm add @lingva/vue
pnpm add --save-dev @lingva/cli
pnpm lingva init --mode local --no-auth --sdk vue
```

Use `createLingvaVue` in browser applications and `createLingvaVueServer` for
request-scoped Nuxt or Vue SSR. The package supports local generated resources
and hosted bundle delivery.

[Read the Vue guide](https://docs.lingva.dev/installation/vue).
