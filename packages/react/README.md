# `@lingva/react`

Typed React provider, hooks, translated text component, and optional in-context
translation inspector for Lingva.

```bash
pnpm add @lingva/react
pnpm add -D @lingva/cli
```

The package supports React 18 and 19 and does not require Lingva's private UI
package or a CSS framework.

[Read the React guide](https://docs.lingva.dev/installation/react).
